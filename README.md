# 大肥鱼桌宠 🐳

一只住在你桌面右下角的大肥鱼（鲸鱼娘）。它会自己待机呼吸、随机做八十多种小动作，也会**看你本地的 WorkBuddy 和 Cursor 在干什么**，然后切成对应的工作状态动画，头顶冒泡告诉你现在在跑哪个项目。

> **2.0 新功能：会聊天的鱼** —— 右键 `💬 跟它聊聊` 弹出聊天窗，打字或点快捷话题跟它对话，它会用语音 + 表情动作回应。配了大模型更聪明（支持 DeepSeek / OpenAI / 本地 Ollama），**没配也能离线聊**，详见 [对话功能](#对话功能会聊天的鱼--20-主打)。

> **3.0 新功能：羁绊进化 + 桌面巡游** —— 亲密度到档会**变身演出**（5 个形态，金色气泡 + 专属动画 + 语音播报），右键 `状态 ▸ 形态` 能看解锁进度、点任意形态回看。右键 `🐾 桌面巡游` 让它沿屏幕底边自己走、定时爬到顶部菜单栏**倒挂**，鼠标靠近会躲开——**免系统授权**。详见 [羁绊进化](#羁绊进化30-5-个形态养它有长期目标) 和 [交互](#交互)。

技术栈：**Electron + 原生 HTML/CSS/JS**（参考 [PC2005-cloud/dsh-pet](https://github.com/PC2005-cloud/dsh-pet) 的桌宠本体设计，去掉了它的插件宿主层，换成直连本机 AI 工具的探测层）。

## 快速开始

```bash
cd ~/WorkBuddy/大肥鱼
npm install
npm start
```

> 如果你是在某个 Electron 应用（WorkBuddy / Cursor / VS Code）的内嵌终端里跑，环境变量 `ELECTRON_RUN_AS_NODE` 会让 Electron 退化成普通 Node 而启动失败。启动脚本里已经用 `env -u ELECTRON_RUN_AS_NODE` 规避掉了。

其它命令：

```bash
npm run selftest   # 无头自检：窗口是否创建、素材是否加载、视频是否解码，结果写 /tmp/pet-selftest.json
npm run probe      # 只测探测层，不弹窗，打印 WorkBuddy / Cursor 当前状态
npm run icon       # 重新生成托盘图标 assets/tray.png
```

## 联动原理

桌宠不连网、不改你的任何配置，只读本机已经存在的文件。

| 工具 | 读什么 | 拿到什么 |
| --- | --- | --- |
| **WorkBuddy** | `~/.workbuddy/workbuddy.db` 的 `sessions` 表 | **`status`（working / completed / error —— 判定以它为准）**、`cwd`（当前项目）、`title`（会话标题）、`updated_at` + `last_activity_at`（两者取更近的当活性） |
| | `~/.workbuddy/changes-index/<sessionId>.json` 的 mtime | 最近一次改文件的时间 → 区分「在想」还是「在写」 |
| **Cursor** | `~/.cursor/projects/<项目>/agent-transcripts/<会话>/*.jsonl` | 会话是否在跑 + **第一条用户消息**（正在处理哪个问题）+ `cwd` |
| | `~/.cursor/ai-tracking/ai-code-tracking.db` 的 `ai_code_hashes` 表 | 最近一次 AI 落文件的时间与文件名（作为兜底信号 + 气泡里显示「在改哪个文件」） |
| **CodeBuddy Code（CLI）** | `~/.codebuddy/projects/<项目>/*.jsonl` | 同上：mtime 判断是否在跑，第一条用户消息当「问题」 |

三个源共用一套会话解析（`src/main/watcher/transcript.js`），Cursor 的字段是 `role:"user"` + `message.content`，CodeBuddy 是 `type:"message"` + `role:"user"` + 顶层 `content`（文本块叫 `input_text`），两种都认；自动跳过 `<system-reminder>`、`<timestamp>` 这些注入块和纯斜杠命令。

**响应延迟**：1 秒轮询打底，再叠一层 `fs.watch` 文件事件（对上述目录监听），文件一改 250ms 内立刻重算，所以体感是亚秒级的。全部只读本地文件，不联网、不改任何配置。

> 踩过的坑：`~/.workbuddy/sessions/*.json` 里的 `lastHeartbeat` **只在会话启动时写一次**，不是心跳，拿它判断存活会得到「永远空闲」。
> 第二个坑：只看 `updated_at` / `last_activity_at` 也会误判——跑一条长命令时这两个字段几十秒不动是常态，结果明明在跑却显示「等你确认」。所以判定改成**以 `status` 为准**：`status=working` 就一定还在跑（改着文件 = working，没改 = thinking），只有当它静默超过 2.5 分钟才怀疑是在等你。

### 六档状态机

| 档位 | 动画 | 触发条件 |
| --- | --- | --- |
| 思考 `thinking` | 工作状态-思考冒泡 | WorkBuddy `status=working` 但最近没改文件（在想 / 在跑长命令） |
| 工作 `working` | 工作状态-忙碌点按 | 20s 内有文件变更，或会话还在写 |
| 整理 `organizing` | 工作状态-清点归档 | 停笔了但还没看到结束标记，最多再算 30s（收尾/等工具返回） |
| 等你 `waiting` | 工作状态-原地踱步张望 | `status=working` 却静默超过 **2.5 分钟**（多半真卡在等你点确认） |
| 搞定 `success` | 工作状态-雀跃庆祝 | **看到结束标记**（Cursor `turn_ended`/status:success、CodeBuddy `turn-metrics`），或 WorkBuddy 会话 `status` 翻到 completed —— 庆祝 35s 后转为摸鱼 |
| 出错 `error` | 工作状态-垂头叹气冒汗 | 结束标记里 status 是 error/fail/abort，或 WorkBuddy 会话状态出错 |
| 摸鱼 `idle` | 待机 + 49 段趣味动画（轮着播，不重复） | 没有任何活跃会话 |

多个来源同时活跃时按优先级取一个：出错 > 等你 > 工作中 > 整理 > 思考 > 搞定 > 空闲。

> 完成判定不靠「多久没写文件」——那样跑完了还会挂着"整理中"两分钟。两个工具都会在一轮结束时往会话文件里打标记：
> Cursor 写 `{"type":"turn_ended","status":"success"}`，CodeBuddy 写 `turn-metrics`。看到标记就算跑完，立刻庆祝，35s 后直接转摸鱼，**不会**退回收尾档。
> 另外还会看最后一条消息是不是 assistant、以及它是不是只在发起 tool 调用（是的话说明还在跑，不算完）。

### 每一步在干嘛（步骤流）

除了档位，桌宠还能显示 agent **当前这一步具体在做什么**（读哪个文件、跑哪条命令、搜什么关键词）。

| 工具 | 步骤数据从哪来 |
| --- | --- |
| **WorkBuddy** | `~/.workbuddy/projects/<项目>/<sessionId>.jsonl` 里的 `{"type":"function_call","name":"Bash","arguments":"{...}"}` |
| **CodeBuddy** | `~/.codebuddy/projects/<项目>/<会话>.jsonl`，同上（`arguments` 也是 JSON 字符串） |
| **Cursor** | 会话 jsonl 里 assistant 消息的 `content[].type === "tool_use"`，`{name, input}` |

统一解析在 `src/main/watcher/steps.js`：读文件尾 256KB（工具参数可能很长，读少了会漏步骤），把工具名翻成中文动词：

```
Read/Write/Edit/StrReplace → 读 / 写 / 改      Grep → 搜   Glob → 找
Bash/Shell/Terminal        → 跑命令（node -e、python -c 归为"跑脚本"）
WebSearch/WebFetch         → 搜网页 / 看网页    Task* → 建任务 / 更新任务
AskUserQuestion → 问你      Skill → 用技能       show_widget → 画图
```

展示位置：

- **气泡**：新增一行 `› 改 src/main/steps.js`（等宽字体小灰条）
- **右键菜单**：「最近步骤（WorkBuddy）」子菜单，列出最近 8 步，新的在上

细节处理：路径会自动相对当前项目显示（`src/xxx.js` 而不是一长串绝对路径）；命令会剥掉前导的 `cd xxx &&` 和 `PYTHONDONTWRITEBYTECODE=1` 这类环境变量前缀，否则只剩一个 `cd`，看不出在干嘛。

不想要就在 `pet.config.json` 里设 `steps.enabled: false`。

### 气泡：告诉你「哪个 agent 在处理哪个问题」

气泡是三段式的，颜色徽章区分 agent：

```
[WorkBuddy] 规划开发大肥鱼桌面宠物      ← 徽章（agent）+ 问题（会话标题/首条用户消息）
手上这摊马上就好                        ← 该 agent 专属口吻的文案
工作中                                  ← 档位 · 正在改的文件（Cursor 有）
```

- 徽章颜色：**WorkBuddy 蓝 / Cursor 橙 / CodeBuddy 紫**，在 `pet.config.json` 的 `agents` 里改
- 「问题」优先用会话标题，拿不到就退回项目名（最长 26 字，超出截断）
- 每个 agent 有一套自己的说法（见 `textsBySource`）：WorkBuddy 偏小助理、Cursor 偏「改代码」、CodeBuddy 偏「终端跑命令」。查不到就退回通用 `texts`
- 托盘悬停提示也是同样的「agent · 档位 · 问题」

**右键 → `各 agent 状态`** 会列出三路各自的实时状态（哪个在忙、忙哪个项目/问题），点某一路可以让鱼立刻切过去显示它——不会只看得到「最忙的那个」。

**右键 → `它在干嘛？`** 是"手动催它汇报一次"：当场探一次三家的状态，然后**明确开口答你一句**——闲着就说「现在三家都没在跑，我一个人摸鱼呢~」，忙着就说「Cursor 正在工作中：xxx，我盯着呢~」，配一个动作和 Q 弹，说完几秒自动恢复。台词在 `speak.idleLines` / `speak.busyLines` 里改（`{agent}` `{phase}` `{what}` 是占位符），动作用 `speak.anims`。

> 踩过的坑：这个菜单项早先只是把当前状态当成一次"强制更新"重推一遍（`onState(force)`），没有专属反馈。结果 idle 时反而是 `hideBubble()` 把气泡藏了、忙碌时又显示原来那句台词——用户点下去几乎看不出变化，等于"没反应"。现在改成专属的 `pet:speak` → `onSpeak`：独立台词池 + 动作 + Q 弹，且不受 `poll()` 的 10 秒去重影响，探不到就用上次状态兜底，保证一定有回应。

### 对话功能（会聊天的鱼 · 2.0 主打）

右键 `💬 跟它聊聊`（托盘里也有）弹出一个独立聊天窗：打字回车发送，或点快捷话题。它收到后**在桌宠身上播一个动作 + 冒泡 + 语音念出来**，聊天窗里同步显示对话记录。之所以用独立窗口而不是在鱼旁边放输入框——桌宠窗口是 `focusable: false` 的透明置顶窗，根本接不了键盘焦点。

**两级回答，永远有回应：**

1. **在线（配了大模型）**：走 OpenAI 兼容的 `/chat/completions` 接口，还把当前工作状态当上下文喂进去（问"你在干嘛"它会结合 WorkBuddy/Cursor 的状态答）。System prompt 把它设定成"蓝发女仆鲸鱼娘、简短可爱、偶尔傲娇"。
2. **离线（没配 / 超时 / 报错）**：自动回退到内置意图库——关键词匹配 13 类意图（问候、名字、在干嘛、夸奖、笑话、关心、感谢、无聊、天气、时间、表白、吐槽、告别），每类多个动画 + 台词池随机抽；没命中也有兜底闲聊。**打包发给别人，对方什么都不配也能聊。**

**配大模型（可选）**：在 `~/Library/Application Support/dafeiyu-pet/chat.json` 写（这个文件不存在就是离线模式）：

```json
{
  "enabled": true,
  "baseUrl": "https://api.deepseek.com/v1",
  "apiKey": "sk-xxxxxxxx",
  "model": "deepseek-chat",
  "timeoutMs": 12000
}
```

- `baseUrl` + `model` 换成任意 OpenAI 兼容服务：OpenAI 官方、通义、Moonshot、本地 Ollama（`http://localhost:11434/v1`）都行；`apiKey` 本地 Ollama 随便填个非空值。
- **apiKey 只存本地 `userData/chat.json`，不进源码、不进默认配置、不进分发包**，改完不用重启，下次发话生效。
- 聊天窗底部会显示当前是「在线 · 大模型」还是「离线模式」。离线是黄底气泡，在线是白底。

> 设计取舍：对话是 dsh-pet 原作的核心，但它依赖 DSH 的模型接口，跟本机联动无关，所以之前一直没做。2.0 用"可配置模型 + 离线兜底"补上——既不绑架用户必须用某家模型，又保证开箱能聊。相关逻辑在 `src/main/chat.js`，意图匹配和上下文替换都是纯函数，自检里直接断言。

### 点击音效

点一下鱼身（按下后**没拖动**才算，拖走/扔出去不响）会播一个随机音效，同时随机播一段「点击回应」动画 + 冒一句碎碎念。

音效是**合成的**（`npm run sfx:click` → `assets/sfx/click/`，4 个共 76KB）：

| 文件 | 时长 | 手感 |
| --- | --- | --- |
| `bounce.wav` | 215ms | Q 弹，最「果冻」，默认主力 |
| `pop.wav` | 155ms | 啵，短促上扬，像戳破气泡 |
| `boing.wav` | 300ms | 弹簧，下扫再弹上去再落回来 |
| `tick.wav` | 95ms | 咔，极短极脆，连点不糊 |

合成思路参考 [MerZlin/dsh-pet-indesktop](https://github.com/MerZlin/dsh-pet-indesktop) 的 `scripts/make_click_sound.py`：**主弹（被按下去）+ 一小段更轻更短的回弹（弹起来）**，两段叠出果冻感。改了一处——扫频用真正的相位积分（`ph += 2π·f/RATE`）而不是 `sin(2π·f(t)·t)`，后者瞬时频率是 `f(t) + t·f'(t)`，下扫会扫过头、音高飘。

**音效包机制**：`assets/sfx/click/` 下所有音频都算一个包，点击时随机挑一个，**想加自己的音效直接往里丢 wav/mp3 就行，不用改代码**（会自动避开连续两次放同一个）。

配置在 `sound.click`：`enabled` / `volume`（默认 0.5）/ `minGapMs`（默认 200，连点时不糊成一片）。右键菜单 **「点击音效：开/关」** 可切换，切完立刻响一声确认。

> 音效走主进程 `afplay`，不经过渲染层——跟状态播报一样，窗口没焦点也响，不受 Chromium 自动播放策略限制。

### 喂鱼 + 饱腹度 + 节日彩蛋

右键 **「喂点东西」** —— 食物标签从右上角飘到鱼嘴边，然后播一段「吃 XX」动画，气泡冒一句「谢谢款待~」。

**17 段吃动画素材直接复用**，不用新增任何素材：吃早餐 / 午餐 / 晚餐 / 西瓜 / 糖葫芦 / 冰淇淋 / 青团 / 粽子 / 汤圆 / 腊八粥 / 重阳糕 / 长寿面 / 大闸蟹 / 饺子 / 年糕 / 白饭 / Token。

**饱腹度**（0~100，初始 70，每小时掉 5）：

- **不用定时回写**。存档里只放「上次的值 + 当时的时间戳」，读取时按过去了多少小时现算衰减。所以关掉桌宠再打开、甚至隔了三天，算出来的都是对的，不需要后台跑计时器
- 喂一次涨 20~30，上限 100
- 低于 25 会**自己嘟囔**：待机时有概率播「碎碎念」动画 + 冒「肚子好饿呀…」
- 高于 90 会喊「吃撑了，动不了…」

**今天吃什么**（优先级从高到低）：

1. **生日** → 吃长寿面（在 `feed.birthday` 填 `MM-DD`）
2. **农历节日** → 春节年糕 / 元宵汤圆 / 端午粽子 / 中秋大闸蟹 / 重阳重阳糕 / 腊八腊八粥
3. **时段** → 早上早餐、中午午餐、晚上晚餐（权重 3）
4. **时令** → 春青团 / 夏西瓜·冰淇淋 / 秋糖葫芦·大闸蟹 / 冬饺子·年糕（权重 1）
5. 兜底 → 白饭、Token

时段权重给 3 是因为测出来八点钟有 2/3 概率给糖葫芦——八点更该想吃早餐。

**节日用的是农历**，靠 `Intl.DateTimeFormat` 的 `chinese` calendar 算（`2026-09-25 → 八月十五`），不引第三方库，也**不用每年手工改日期表**。

配置在 `feed` 段，食物映射、台词、衰减速度都能改。

### 心情 + 亲密度（会闹脾气，也会跟你混熟）

它不只会报告状态，**自己也有情绪**。右键菜单底部能看到「心情：X · 亲密度：N%」。

**心情**：把最近 30 分钟里的成败记成流水，成功 +1、失败 −1.5，加总出 `happy / calm / sad`。

- **顺的时候**（happy）：待机时有 30% 概率自己雀跃一下，播「工作状态-雀跃庆祝」
- **蔫的时候**（sad）：待机时有概率播「工作状态-垂头叹气冒汗」，偶尔叹一句「唉，又没跑通…」
- **连续失败 3 次**进入**赌气**状态（持续 4 分钟）：这时候戳它，不给好脸色，扭头播「点击回应-傲娇生气」+「哼，不理你！」

跟饱腹度同一个套路：流水存时间戳 + 时间窗口，读取时现算，**不跑计时器**；同一次结果只记一次，重复推送不会把失败数刷上去。

**亲密度**（0~100，初始 20）：戳一下 +1、喂一口 +2，**长期不理就掉**（每小时 0.6，约一天掉 14）。分五档解锁台词：

| 亲密度 | 称呼 | 会说什么 |
| --- | --- | --- |
| 0~ | 认生 | 「你…你是谁呀」「别靠太近啦」 |
| 20~ | 面熟 | 「哦，是你呀」「今天也来啦」 |
| 45~ | 熟人 | 「你来啦，等你半天了」「摸摸头~」 |
| 70~ | 要好 | 「最黏你了~」「不许走，再陪我一会儿」 |
| 90~ | 形影不离 | 「我们已经是老搭档啦」「这辈子跟定你了」 |

到档之后戳它有 50% 概率说这些，没到就退回通用闲聊。衰减靠「上次互动时间」现算，同样不跑计时器。

### 羁绊进化（3.0：5 个形态，养它有长期目标）

亲密度不只是换台词，现在也是**进化等级**。到档那一刻播一段变身演出——金色描边气泡 + 专属动画 + 语音播报——并把解锁的形态记进 `~/Library/Application Support/dafeiyu-pet/evolve.json`：

| 亲密度 | 形态 | 特权（文案） | 进化动画 |
| --- | --- | --- | --- |
| 0~ | 初见 · 怯生生 | 会偷偷看你一眼 | 待机呼吸休闲 / 照镜子 |
| 20~ | 面熟 · 小跟班 | 会主动跟你打招呼 | 原地360度旋转展示 |
| 45~ | 熟人 · 元气搭档 | 解锁撒娇和更多碎碎念 | 女仆屈膝礼仪 |

- **复用现有的 5 档亲密度**，不另造经验值——两套养成数值会打架（喂一次到底涨哪个？）。所以 `bond` 那张表同时就是进化表，喂食/戳它涨亲密度的同时就在推进进化。

- 中间跳过多档（比如亲密度一次涨很多）会把跳过的档一并补记为已解锁。
- 关闭：把 `evolve.enabled` 设 `false`。形态配置在 `evolve.forms`，每档的 `formLabel / perkText / anims / lines` 都能改。

### 戳它的反应跟着心情和亲密度走

5 段「点击回应」以前是**纯随机**抽的，戳一百次，反应跟你最近顺不顺、跟你俩熟不熟完全无关。现在按顺序匹配 `click.rules`，命中第一条就用它的动画和台词，都没命中才退回随机：

| 顺序 | 条件 `when` | 动画 | 什么时候会看到 |
| --- | --- | --- | --- |
| 1 | `sulk` | 点击回应-傲娇生气 | 连续失败正在赌气，戳它不给好脸色 |
| 2 | `greet` | 点击回应-元气挥手 | 隔了 `greetAfterMs`（默认 2 小时）没理它 |
| 3 | `bond:best` | 点击回应-挠痒咯咯笑 | 亲密度到「形影不离」 |
| 4 | `bond:close` | 点击回应-开心跃动 | 亲密度到「要好」 |
| 5 | `mood:happy` | 点击回应-开心跃动 | 最近 30 分钟很顺 |
| 6 | `mood:sad` | 点击回应-害羞惊讶 | 最近不太顺 |

两条要注意：**顺序就是优先级**（档位规则排在心情规则前面，所以亲密度满档时会先走 `bond:best`）；`greet` 用的是亲密度存档里那个 `at` 时间戳，也就是「上次戳它/喂它的时刻」，**跨重启也记得住**，刚开机不会莫名其妙说「好久不见」。

### 冷落太久，它主动来找你（`src/main/lonely.js`）

亲密度一直是**单向**的：不理它就往下掉，但它没有任何主动挽回的动作。这很不对称——你怠慢它，它只是默默变冷淡，不会设法引起你注意。

现在补上另一端：**三家都闲着 + 冷落超过 45 分钟**，它自己播「原地敲击桌面互动」或「鲸鱼吐泡泡特效」来提醒你它还在，台词里还会带上当前的亲密度档位（「你是不是把我忘啦，我们都退回「面熟」了」）。这两段素材之前完全没接线，恰好就是「主动发出动静」的样子。

三个刻意的约束：

- **有 agent 在忙就不来打扰**。你在干活的时候它凑过来，是烦不是可爱
- **刚开机不会扑上来**。起算点取「本次开机」和「上次理我」里**较晚**的那个，得是这次运行里真的冷落了它这么久才算
- **冷却 25 分钟**，不会一直敲桌子

「上次理我」的时间戳不用新记——亲密度衰减本来就从这个时刻起算（`bond.at`），顺手拿来用。

### 三个新互动：让它更像「养着一只会回应你的宠物」

这三个都是「浅联动」——只读本机状态、只在桌宠窗口里做反应，不碰工具本身。

**分部位摸**（`pet.config.json` 的 `click.parts`，渲染层 `partAt()`）纯渲染层实现：按鼠标点在命中区的相对高度切三段，各段有自己的动画池 + 台词池。命中区分上/中/下是 `bands: [0.34, 0.68]` 两个阈值定的，改阈值就能调三段的胖瘦。判定顺序是「特殊规则 → 部位池 → 兜底池」，所以它跟赌气/久别重逢那套规则不冲突。

**猜拳**（主进程 `rpsDecide()`）判定抽成纯函数：三种互克 + 平局，自检里五种组合全覆盖（早先写反成「它赢玩家」，自检当场抓出来了）。结果推给渲染层播对应动画 + 台词；快乐/生气各记一笔小金库，平局不动账。

**递小纸条**（`src/main/note.js`）跟「冷落来找你」正好互补——那个是全家闲着才来，这个是**你在忙时才递**。判定 `shouldFire(cfg, last, busy, now)` 抽成纯函数好自检：没在忙 / 没到 30 分钟间隔都不递。便签外观是纯 CSS（`.bubble.note` 的淡黄渐变 + `::before` 胶带 + `::after` 折角 + 楷体），一次性——下次普通气泡出现或超时隐藏就自动恢复。这里踩过一个坑：一开始给便签标签写了内联 `style="display:none"`，被 CSP 的 `style-src 'self'` 拦下，自检的 `rendererError` 当场报出来，改成 CSS 类控制就好了。

### 文案：432 句，且一轮之内不重复

之前最大的问题是**戳它只有 5 句闲聊**在循环（`idleTexts`），所以体感就是「来回来去那几句话」。现在扩到 432 句：

| 场景 | 句数 | 场景 | 句数 |
| --- | --- | --- | --- |
| 三家专属档位台词 | 144 | 戳它的闲聊 | 48 |
| 通用档位台词 | 54 | 亲密度五档 | 35 |
| 点击规则台词 | 32 | 心情（顺/蔫/躺平） | 24 |
| 喂食 | 20 | 作息 + 摸鱼阶梯 | 21 |
| 悬停 / 冷落 | 12 / 12 | 每日回顾 | 14 |

三家说话方式是分开写的：WorkBuddy 像助手（「这个我来处理，你歇着」），Cursor 像编辑器（「整理 diff 中~」「可以 commit 啦」），CodeBuddy 像终端（「等你敲个 y~」「看看输出里说什么」）。

**光加量不够，还改了抽取机制。** 纯随机 48 句也经常连着说同一句——概率上讲，抽 10 次里有重复的概率超过 60%。所以台词改成**洗牌袋**：每个场景一个袋子，抽空了才重新洗牌，保证一轮之内绝不重复；跨轮接缝处也会避开「上一轮最后一句」。

```js
pickLine(cfg.idleTexts, 'idle-chat')   // 48 句里轮完一遍才可能重复
```

key 不同则袋子独立，「戳它的闲聊」和「悬停台词」互不干扰。改完配置（增删句子）袋子会自动重洗，不用清存档。

### 待机动画不再来回来去那几段

跟文案一样的问题，而且更隐蔽。模拟 200 次待机切换，改之前：

```
前 10 段吃掉 68.5% 的曝光；「东张西望」一段独占 26 次（13%）
200 次里只出现过 51 种素材，31 种只露过一次面
```

根因有两条：

**1. 权重是按「池」给的，不是按段数给的。** turn 池只有「东张西望」一段，却给了 4 的权重 → 它一个人拿走 13.3%，而 74 段的趣味池每段只有 0.4%。段越少的池，每段概率越暴涨。

**2. 池内是纯随机**，4 段的待机池会连着播同一个（模拟里相邻重复 6 次）。

改了三处：

- **权重重配**：`idle 10→6`、`turn 4→2`、`fun 9→16`
- **池内也走洗牌袋**：49 段趣味素材轮过一遍才可能重复
- **专属素材从待机池摘出来**（见下）

改后再模拟 200 次：**前 10 段占比 68.5% → 47.0%，相邻重复 6 次 → 0 次，出现的素材 49 → 59 种**，最常出现的一段从 26 次降到 12 次。

### 大招只在特定时刻出现

106 段里有 25 段是**有专属时机**的：成就大招（蓝鲸现世、凭空生花、动物环绕、蝴蝶蜜蜂环绕）、节日动作（舞狮头、放孔明灯、中秋赏月…）、应季（放风筝、堆雪人…）、作息（晨间刷牙、打瞌睡被惊醒）、拆礼物。

以前它们混在趣味池里随机播得到 —— **待机时撞出「蓝鲸现世」，等真达成十连顺时已经不稀奇了**。现在单独收进 `special` 池：菜单里照样能手动点播（分组叫「特殊时刻（平时不自动播）」），但不参与待机随机。

素材池随之变化：趣味 74→49，新增特殊时刻 25。

### 悬停反应（盯着它看会害羞）

鼠标在鱼身上**停住 1.2 秒**（不点、不拖）→ 播「点击回应-害羞惊讶」，随机冒一句「盯着我干嘛呀…」/「再看我就要害羞了」/「有什么事吗~」。

- 冷却 **30 秒**，不然一直盯着它就一直害羞，很吵
- 鼠标一动就重新计时，移开或按下就取消
- **开了鼠标穿透就没有这个反应**（穿透后窗口收不到任何鼠标事件，这是设计如此，不是 bug）

配置在 `hover` 段：`enabled / afterMs / cooldownMs / anim / lines`。

### 提示音 / 提示语音

默认 **语音播报**（可爱萝莉音）：状态一变就用系统 TTS 念一句，**每个 agent 音色不同**，不用看屏幕也知道是谁在动。

| 事件 | 什么时候响 | 声音 |
| --- | --- | --- |
| `start` | 某个 agent 开始干活 | 短促上扬的「叮咚」 |
| `done` | 一轮跑完（看到结束标记） | 三音上行 |
| `error` | 出错 | 两音下行 |
| `waiting` | 真卡在等你确认 | 门铃式两声 |

音色按 agent 区分：**WorkBuddy 620Hz 温和 / Cursor 760Hz 偏亮 / CodeBuddy 500Hz 低沉**（`scripts/make-sfx.js` 里改基频和泛音配比）。

**语音模式**（默认）走两级回退链，哪档能用就用哪档：

| 引擎 | 音质 | 联网 | 依赖 |
| --- | --- | --- | --- |
| `edge`（默认） | 好，微软神经网络音色 | **首次需要**，之后永久离线 | `python3 -m pip install edge-tts`（几 MB） |
| `say` | 一般，机械味 | 不需要 | macOS 自带，零依赖 |

> 关键设计：台词一共就 6 句（4 个事件 × 3 个 agent 名），**首次联网合成完就缓存到 `~/Library/Caches/dafeiyu-tts/`**，之后完全离线播放。断网且没缓存时才退回系统 `say`。

> 曾经还接了一档本地离线神经 TTS（sherpa-onnx + Kokoro / Theresa / MeloTTS），但音质明显不如 Edge，
> 且模型要 1.4GB，已移除。`sfx.js` 里 `kokoro` / `vits` 引擎的代码还留着，想接回来的话
> 把模型放进 `assets/tts/` 并在 `sound.voice` 里加回对应的 `tts` 配置块即可。

**Edge 引擎配置**（`sound.voice.edge`）：

| 配置项 | 默认 | 说明 |
| --- | --- | --- |
| `edge.voice` | `zh-CN-XiaoyiNeural` | 音色。晓伊（活泼）/ 晓晓（温柔）/ 晓北（东北）/ 晓妮（陕西） |
| `edge.rate` | `+10%` | 语速。萝莉感靠「稍快 + 稍高」，`+15%` 更明显 |
| `edge.pitch` | `+10Hz` | 音调偏移，`+20Hz` 更稚嫩 |
| `edge.python` | 绝对路径 | 装了 `edge-tts` 的 python。**打包版从 Finder 启动时 PATH 很窄，必须写绝对路径**；找不到会自动探测 PATH / homebrew / `/usr/bin` |

换音色：**右键 → 挑语音音色…** 打开试听页，点播放试听，满意后点「复制配置」贴进 `pet.config.json`。换完跑一次 `node scripts/warm-voice.js` 把新音色的台词重新缓存一遍（加 `--force` 强制重录）。

默认台词（`{agent}` 换成 agent 名、`{what}` 换成正在处理的问题）：

```json
"lines": {
  "start":   "{agent}开始干活啦~",
  "done":    "这一轮搞定啦，真棒！",
  "error":   "诶呀，好像出错了呢",
  "waiting": "主人，等你确认一下下~"
}
```

**音效模式**是手写合成的（基频 + 二次/三次泛音 + 指数衰减包络，直接写 WAV 头），`npm run sfx` 生成 12 个文件共 600KB —— 不引音频库、不用第三方素材，也就没有版权问题。语音不可用时（比如非 macOS）会自动退回音效。

几个防吵的设计：

- 只在**状态真的变化**时响，「在想 / 收尾」这两个档位默认不响
- 从「在想」回到「开工」不算新一轮，不重复响
- 6 秒节流（连续变化只响一次）
- **刚启动那一下不响**，免得每次开桌宠都「叮」
- 播放走系统 `afplay`、不经过渲染层：窗口没焦点也响，也不受 Chromium 自动播放策略限制

右键菜单的 **「提示音：语音 / 音效 / 关」** 是三态循环，切完立刻念一句让你听效果，选择会记住。音量和事件映射在 `pet.config.json` 的 `sound` 字段里改：

```json
"sound": { "enabled": true, "mode": "voice", "volume": 0.35, "minGapMs": 6000,
  "voice": {
    "engine": "edge",
    "edge": { "voice": "zh-CN-XiaoyiNeural", "rate": "+10%", "pitch": "+10Hz" },
    "lines": { ... }
  },
  "on": { "working": "start", "success": "done", "error": "error",
          "waiting": "waiting", "thinking": false, "organizing": false } }
```

## 交互

- **点播任意动画** —— 右键 → `动作`，106 段动画按「工作状态 / 待机 / 走路 / 点击回应 / 碎碎念 / 余额 / 转身 / 趣味 / 特殊时刻」分组全在菜单里，点哪段播哪段。点播「走路」类时它会**真的在屏幕上走一段**（130~300px，会被屏幕边界夹住），走完落地 Q 弹一下。手动点播后 9 秒内屏蔽状态机，不会被工作状态当场抢回去
- **点击** —— 附带 Q 弹挤压和一句碎碎念。动画分两层：**平时**（没命中任何特殊条件）从 `click.fallbackAnims` 的 19 段里用洗牌袋抽，一轮内不重复，里面除了 5 段「点击回应」还混了「被吓一跳 / 偷吃零食被抓住 / 转个圈 / 吐泡泡 / 变鸽子」这类即时反应；**特殊时刻**（赌气 / 久别重逢 / 亲密度到档 / 心情好或差）走 `click.rules` 里对应的一小池（各 4~5 段语义相近的动作），命中第一条就不看后面。台词同样各池独立走洗牌袋
- **分部位摸** —— 点鱼身**不同高度**反应不一样：按 `click.parts.bands`（默认 [0.34, 0.68]）把命中区切成上/中/下三段，点**头**（害羞惊讶…）、点**肚子**（可爱宅舞 + 咕噜噜有点饿）、点**尾巴**（尾巴拍地 + 再拽就打你），各有自己的动画池和台词池。三段都命中特殊规则时以规则优先，otherwise 才落到部位。关掉的话把 `click.parts.enabled` 设 `false`
- **悬停** —— 鼠标停在鱼身上不动 1.2 秒，它会害羞，从 `hover.anims` 的 5 段里抽一段（害羞惊讶 / 被吓一跳 / 照镜子 / 「是啊，吃什么」/ 偷吃被抓），配一句「盯着我干嘛呀…」这类台词。30 秒冷却，鼠标一动就重新计时；开了鼠标穿透则没有
- **猜拳** —— 右键 → `猜个拳` → 我出石头/剪刀/布，它随机出手，按「石头砸剪刀、剪刀布、布包石头」判胜负。赢/输/平各播一段动画 + 台词，赢了记一笔小金库、输了扣一笔。判定是纯函数，自检里五种情况全过
- **递小纸条** —— 你埋头干活时，隔一阵子（默认 30 分钟，`note.everyMs` 可调）它递一张**关怀便签**给你：淡黄便签纸 + 胶带 + 折角，写句「喝口水吧」「起来走两步」「别熬太晚」。只在有 agent 在忙时自动递（你摸鱼时不打扰）；想随时看就右键 → `递张小纸条` 手动要一张
- **桌面巡游（3.0，行为状态机）** —— 右键 `🐾 桌面巡游`，再点一次 `🐾 停下巡游`（托盘里也有这个开关）。它不是匀速贴纸滑行，而是一套**会自己换的行为**：漫步 → 停下来**东张西望** / **照镜子** / **伸懒腰打哈欠** → 偶尔**小跑**一段 → 沿就近边缘爬到**顶部菜单栏倒挂** → 再爬下来。每种行为配了各自的动画和台词（见 `crawler.activities`），头顶气泡随行为切换，停下就收掉。**鼠标靠近 170px** 会随机给三种俏皮反应——**害羞**（「呀！被你发现了」）、**打招呼**（挥手屈膝）、**溜走**（转身就跑）；**巡游中直接戳它**也会触发害羞/打招呼。手动拖 / 抛掷 / 点「走路」类动画 / 回到右下角，都会自动停下巡游把窗口交还给你。开关写进配置，**重启后接着爬**。全程只用窗口坐标 + 全局鼠标位置，不读别的窗口、**不需要系统授权**
  - 演化史：第一版「匀速直线 + 循环一段动画 + 固定频率上下颠」被吐槽「太呆、像木偶」。现在的解法是**行为状态机**：速度用 `vx` 缓动逼近目标（漫步慢、小跑快、驻足为 0，起步刹车自然），行为到期主动切换，反应式互动随机挑一种。彻底删掉了那个固定颠簸的 CSS 动画——机械感就来自它
  - 踩过的坑：平移用「速度 × dt」会掉帧——定时器偶尔卡一下 `dt` 变大，那一帧鱼突然蹦十几像素。改成**固定步长 + vx 缓动**后位移恒定，帧率再抖也不跳步。坐标没变化不再重复调 `setPosition`（macOS 每次调用触发整窗重绘合成），鼠标位置从每帧降频到每 4 帧取一次
- **拖拽** —— 按住拖走，松手时带速度就抛物线飞出去，撞屏幕边缘反弹、落地摩擦停稳
- **命中区** —— 只有贴着鱼身的一块圆角区域能接收鼠标，四周的透明像素点不动它。默认 128×146（窗口 320×280 的 21%），在 `pet.hitArea` 里能改，改完右键「重载配置」立刻生效
- **右键** —— 顶层只留高频操作，其余收进三个子菜单（早先 31 项全平铺太臃肿，现在 16 项）：
  - **顶层**：💬 跟它聊聊 / 摸一下 / 猜个拳 / 递张小纸条 / 喂点东西 / 动作（点播素材）/ 它在干嘛？/ 🐾 桌面巡游
  - **状态 ▸**：心情、亲密度、**形态（羁绊进化）**、饱腹度、小金库、今天干了啥、成就、各 agent 状态、最近步骤
  - **打开 ▸**：打开 WorkBuddy / Cursor、用 Cursor 打开当前项目、终端打开、访达显示
  - **设置 ▸**：提示音、挑音色、点击音效、鼠标穿透、回到右下角、重载配置
  - 自检里加了 `menuLayoutOk`：顶层 ≤16 项 + 三个分组齐全 + 核心互动（含聊天、巡游）在顶层，防止以后又堆回几十项
- **托盘** —— 菜单栏常驻，悬停显示「大肥鱼 · agent：档位 · 问题」，菜单里也有**鼠标穿透开关**
- **鼠标穿透** —— 默认**关闭**（整窗可点、可拖）。**开启后整窗彻底不接收鼠标事件**，鱼变成纯装饰，鼠标直接穿过去点到下面的窗口，视觉上它会淡下去（opacity 0.55）作为反馈。因为开了之后右键菜单也唤不出来，开关在**托盘菜单里也放了一份**，随时能关回来（右键菜单和托盘菜单的文案会同步）

> **命中区是量出来的，不是拍脑袋定的**：素材 640×360 里鱼的包围盒（非透明像素）稳定在 `x 211~426 / y 61~330`，六种动画几乎一致，说明所有素材共用同一套构图。按 `object-fit: contain` 贴底换算到 320×280 窗口后，鱼只占中间 **33% 宽、48% 高**那一条（约 106×134px）——窗口里大半是空的透明像素。早先事件监听挂在铺满窗口的 `#stage` 上，所以点空白处也能把鱼拖走。现在 `#stage` 设 `pointer-events: none`，只留 `#hit` 接收。测量方式是 Electron 里 `drawImage(video)` 到 canvas 后读 alpha 通道算包围盒（本机没装 ffmpeg）。

> 早期实现是「鼠标挪到鱼身上就恢复可点击」，听起来贴心，**实际等于没开**：鼠标不在鱼身上时穿不穿透都没区别（你本来也点不到鱼），而鼠标一到鱼身上又被恢复了。而且 hover 状态跟开关不同步——切换瞬间鼠标正好在鱼身上的话，渲染层的 `hovering` 已经是 `true`，之后再移动鼠标就不会上报，行为完全取决于切换时鼠标在哪。现在改成彻底穿透，**那套用来「恢复可点击」的 hover 机制（连同 `pet:hover` 通道）已全部移除**；后加的「悬停害羞」是完全独立的另一套（纯渲染层定时器，只在未穿透时有）。

> 踩过的坑：`~/Library/Application Support/dafeiyu-pet/pet.config.json` 只存**位置**和**穿透开关**两样。窗口尺寸、动画映射等一律以 `src/shared/pet.config.json` 为准——早期把整个配置都持久化了，结果改了默认尺寸，旧文件把它盖回去，窗口一直是 240×240，鱼小到抓不住。

> 踩过的坑：**有时候只剩气泡文字、鱼不见了**。气泡是 DOM，永远在；鱼是两个 `<video>` 交替播。早先切换动画是「立刻隐藏旧 video、显示新 video」，但 `pet://` 换 src 之后要异步解码，这段空窗里两个都不出画面，整窗就透明了；更糟的是 `play()` 失败被 `.catch(() => {})` 吞掉，而 `onended` 是播放链唯一的推进路径，一旦不来，状态机直接停死在空白帧。现在等 `loadeddata` / `canplay` 首帧就绪才切，旧画面一直留着；`onerror`、`play()` 被拒、解码超时、播放停滞都有兜底把链往下推（`pet.playGuardMs` / `pet.playStallMs` 可调）。对照实验：连续快速切换 24 次，旧逻辑 24 次出现「可见但无画面」，新逻辑 0 次。另外逐段扫过 106 个素材，画面覆盖率 10.4%~32.9%，没有一段是空的，所以不是素材的问题。

> **改权重时注意：权重是按「池」给的，不是按段数。** 只有 1 段的池（比如转身）给 4 的权重，那一段就会独占 13%；74 段的趣味池给 9，每段反而只有 0.4%。调权重前先想清楚「这个池有几段」。

> 想让某段素材只在特定时刻出现，把它写进 `achievements` / `calendar` / `routine` / `coins.giftAnims` 里就行 —— `animations.js` 会自动把这些配置里出现过的素材收进 `special` 池，不再参与待机随机。不用手工维护排除名单。

npm run dist       # 产出 dist/大肥鱼.app（约 305MB：Electron 框架 250MB + 素材 52MB）
npm run dist:dmg   # 顺带打一个 dmg 安装包

> plutil -replace CFBundleName       -string "大肥鱼" dist/大肥鱼.app/Contents/Info.plist
> plutil -replace CFBundleIdentifier -string "com.danghaoyu.dafeiyu-pet" dist/大肥鱼.app/Contents/Info.plist
> codesign --force --deep --sign - dist/大肥鱼.app
> ```
> Electron 的加载顺序是 `app.asar` → `app/` → `default_app.asar`，所以放进 `Contents/Resources/app/` 就会优先加载我们的应用，不用去动 `default_app.asar`。

打包后首次启动注意两点：**先退出 `npm start` 那个实例**（否则桌面上会有两条鱼）；**窗口位置会回到默认右下角**，因为 bundle id 变了，配置存在新的 userData 目录里。

### 发给别人：第一次打开被拦怎么办

用 ad-hoc 自签名（`codesign --sign -`），没买 Apple 开发者证书，所以**别人下载过去一定会被 Gatekeeper 拦**：

> 无法打开"大肥鱼"，因为 Apple 无法检查其是否包含恶意软件。

这不是文件坏了。解决办法写在 **[首次打开说明.md](./首次打开说明.md)** 里，分发时把这个文件和 `.app` 一起打包：

```bash
# 产出 dist/大肥鱼.zip：里面是一个「大肥鱼」文件夹，含 大肥鱼.app + 首次打开说明.md
mkdir -p /tmp/大肥鱼分发/大肥鱼
ditto dist/大肥鱼.app /tmp/大肥鱼分发/大肥鱼/大肥鱼.app
cp 首次打开说明.md /tmp/大肥鱼分发/大肥鱼/
ditto -c -k --sequesterRsrc --keepParent /tmp/大肥鱼分发/大肥鱼 dist/大肥鱼.zip
```

对方最快的解法是：**把 app 拖进「应用程序」→ 右键 → 打开 → 点「打开」**。

想彻底根治只能上 Apple 开发者证书（¥688/年）：拿到 `Developer ID Application` 证书后，签名改成 `codesign --sign "Developer ID Application: ..." --options runtime --timestamp` 并走 `xcrun notarytool submit` 公证。这台机器上 `security find-identity -p codesigning` 目前是 0 个身份，所以暂时做不到。

## 已知限制 & 后续可做

1. **状态是推断的，不是事件**。现在靠轮询文件时间戳，粒度到「秒」。想要「这一步 Bash 跑完了」这种精确事件，需要给 CodeBuddy Code 的 `~/.codebuddy/settings.json` 配 hooks，在 `UserPromptSubmit` / `Stop` 时 POST 给桌宠——这是侵入式改动，等你想要再说。
2. **素材是复用的**，授权见下。想彻底自有化，可以走 dsh-pet 的素材链（AI 生成 + 绿幕抠像 + 转 VP9-Alpha webm），需要 brew 装 ffmpeg。
3. 只打了 **macOS arm64**（你本机架构）。要出 Intel 版或 Windows / Linux 版，改 `build.mac.target` 并加对应平台配置即可。
4. **对话已做（2.0）**，但大模型要自己配（见上文「对话功能」）；不配就用离线意图库，不算真·AI。「余额」只做了我们自己这套小金库（赚币 / 分档 / 拆礼物），不是接真实额度——两家的 jsonl 里都没有 token usage 字段，做不出真实数字。
5. 想让它接更多 agent：复制 `src/main/watcher/` 下任意一个探测源，照 `workbuddy.js` 的样子加一个即可，聚合逻辑不用动。
6. **桌面巡游只走屏幕边缘**（底边 / 顶部菜单栏），不会站到任意窗口标题栏上——那要读别家窗口的标题栏，需要 macOS 辅助功能 / 屏幕录制授权，跟「只读、不侵入工具」的初衷冲突，所以基础版没做。倒挂只是把鱼翻 180°，不依赖系统直方图。
